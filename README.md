# Лабораторная работа №2

## Особенности проекта

* Базовый дизайн инкапсулирован во внешнем файле `style.css`.
* Цвета и шрифты управляются централизованно через переменные `:root`.
* Локальные стили применяются точечно: внутренний `<style>` для квадратных маркеров и inline-атрибут для flex-сетки формы.
* Макет использует комбинированное позиционирование (`static`, `relative`, `absolute`).
* Интерфейс реагирует на действия пользователя через состояния `:hover`, `:active`, `:focus` и `:visited`.
* Декоративные волны у проектов (`::before`, `::after`) анимированы ключевыми кадрами `shake` при наведении.
* Кнопка отправки формы имеет плавную микроинтеракцию (уменьшение до 98% при клике).
* Тёмно-сине-фиолетовая цветовая гамма отвечает строгим стандартам высокой контрастности.

## Запуск

Откройте файл `index.html` в браузере.

## Проверка

HTML- и CSS-код успешно провалидированы с помощью сервисов W3C.
